桌面图标开关 v1.1（DesktopIconToggle）
=====================================

功能
----
双击 Windows 桌面空白处，可隐藏全部桌面图标；再次双击即可恢复显示。
双击桌面图标、任务栏或普通应用窗口不会触发。

使用方法
--------
1. 双击 DesktopIconToggle.exe 运行，无需安装。
2. 程序启动后常驻任务栏右下角的系统托盘。
3. 右键托盘图标，可以手动切换图标、设置开机自动启动、打开诊断日志或退出。

系统要求
--------
Windows 10 或 Windows 11，支持高 DPI 与多显示器缩放。

提示
----
程序只控制桌面图标的显示状态，不会删除、移动或修改桌面文件。
如果 Windows SmartScreen 提示未知发布者，这是因为程序没有商业代码签名；
确认文件来自 https://github.com/gwanting/DesktopIconToggle 后，
可选择“更多信息”→“仍要运行”。

问题诊断
--------
如果切换失败，请右键托盘图标选择“打开诊断日志”。
日志默认位于：%LOCALAPPDATA%\DesktopIconToggle\DesktopIconToggle.log
